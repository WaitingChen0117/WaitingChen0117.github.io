# 数据类型与类型转换

> [!info] 一句话概括
> JS 有 7 种原始类型 + 1 种引用类型（Object），转换分显式和隐式，隐式转换是面试高频坑。

## 是什么
- **原始类型（7）**：`string`、`number`、`boolean`、`undefined`、`null`、`symbol`、`bigint`
- **引用类型**：`object`（含 Array、Function、Date 等）

原始类型按值存储在栈，引用类型的引用存栈、数据存堆。

## 类型判断
- `typeof`：区分原始类型，但 `typeof null === 'object'`（历史遗留 bug），函数返回 `'function'`
- `instanceof`：判断原型链，适合引用类型
- `Object.prototype.toString.call(x)`：最可靠，返回 `[object Xxx]`
- `Array.isArray()`：判断数组

## 类型转换
- **显式**：`Number()`、`String()`、`Boolean()`、`parseInt()`
- **隐式**：运算符触发。`+` 有字符串则拼接；其余算术运算转数字；`==` 会转换类型，`===` 不会

```js
[] + []        // ''      （都转字符串）
[] + {}        // '[object Object]'
1 + '1'        // '11'
'1' - 1        // 0
null == undefined  // true
NaN === NaN        // false
```

## 易错点 / 面试追问
- **falsy 值**：`false`、`0`、`''`、`null`、`undefined`、`NaN`，其余皆为 truthy（注意 `[]`、`{}` 是 truthy）
- 优先用 `===`，避免隐式转换
