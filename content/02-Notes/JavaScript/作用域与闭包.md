# 作用域与闭包

> [!info] 一句话概括
> 作用域决定变量的可访问范围；闭包是函数记住并访问其词法作用域的能力，即使函数在作用域外执行。

## 作用域
- **全局作用域 / 函数作用域 / 块级作用域**（`let`/`const` 带来）
- **词法（静态）作用域**：作用域在代码书写时确定，而非调用时
- **作用域链**：内层可访问外层变量，逐层向上查找

## 闭包
函数与其定义时的词法环境的组合。常见形式：函数返回函数，内层引用了外层变量。

```js
function counter() {
  let count = 0;
  return () => ++count; // 闭包，持有 count 引用
}
const c = counter();
c(); // 1
c(); // 2
```

## 应用
- 数据私有化（模块模式）
- 防抖/节流缓存变量
- 循环中用闭包/`let` 保留每次迭代的值

```js
// 经典坑：var + 循环
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 3 3 3
for (let i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 0 1 2
```

## 易错点 / 面试追问
- 闭包会使变量无法被回收，滥用可能导致**内存泄漏**
- 每次调用外层函数都会生成新的闭包
