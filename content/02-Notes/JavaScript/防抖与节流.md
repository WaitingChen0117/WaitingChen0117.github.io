# 防抖与节流

> [!info] 一句话概括
> 都是限制高频事件的触发频率：防抖是"最后一次说了算"，节流是"固定间隔执行一次"。

## 防抖 Debounce
事件停止触发后 n 毫秒才执行；期间再次触发则重新计时。
- 场景：搜索框输入联想、窗口 resize 结束后计算、表单校验

```js
function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

## 节流 Throttle
固定时间间隔内最多执行一次。
- 场景：滚动加载、拖拽、按钮防连点

```js
function throttle(fn, interval) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= interval) {
      last = now;
      fn.apply(this, args);
    }
  };
}
```

## 区别对比
- **防抖**：只在最后触发后执行一次，适合"只关心结果"
- **节流**：过程中匀速执行，适合"需要持续反馈"

## 易错点 / 面试追问
- 防抖可加 `immediate` 参数支持首次立即执行
- 节流有时间戳版和定时器版，可组合实现首尾都执行
- 依赖 [[02-Notes/JavaScript/作用域与闭包]] 保存 timer/last
