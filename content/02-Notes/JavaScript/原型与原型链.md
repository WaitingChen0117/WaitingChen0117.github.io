# 原型与原型链

> [!info] 一句话概括
> 每个对象都有 `__proto__` 指向其构造函数的 `prototype`，层层向上形成原型链，是 JS 继承的基础。

## 是什么
- 函数有 `prototype` 属性（原型对象）
- 实例有 `__proto__`（`[[Prototype]]`），指向构造函数的 `prototype`
- 访问属性时若自身没有，就沿 `__proto__` 向上查找，直到 `Object.prototype`（其 `__proto__` 为 `null`）

```js
function Person(name) { this.name = name; }
Person.prototype.sayHi = function () { return 'hi ' + this.name; };

const p = new Person('a');
p.__proto__ === Person.prototype;              // true
Person.prototype.__proto__ === Object.prototype; // true
```

## 关系图
```
p ──__proto__──> Person.prototype ──__proto__──> Object.prototype ──> null
                        ▲
Person ──prototype──────┘
```

## 易错点 / 面试追问
- `new` 做了什么：① 创建空对象 ② `__proto__` 指向构造函数 prototype ③ 执行构造函数并绑定 this ④ 返回对象（若构造函数返回对象则返回它）
- `class` 是原型的语法糖，`extends` 本质是原型链继承
- `hasOwnProperty` 判断自有属性（不查原型链）
