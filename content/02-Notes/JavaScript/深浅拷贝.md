# 深浅拷贝

> [!info] 一句话概括
> 浅拷贝只复制第一层，嵌套对象仍共享引用；深拷贝递归复制所有层级，完全独立。

## 浅拷贝
- `Object.assign({}, obj)`、扩展运算符 `{...obj}`、`Array.prototype.slice/concat`
- 只复制一层，内层对象仍是同一引用

```js
const a = { x: 1, nested: { y: 2 } };
const b = { ...a };
b.nested.y = 99;
a.nested.y; // 99  ← 内层被共享
```

## 深拷贝
- **`structuredClone(obj)`**（现代浏览器/Node 17+，推荐）
- `JSON.parse(JSON.stringify(obj))`：简单但有坑
  - 丢失 `undefined`、函数、`Symbol`
  - `Date` 变字符串、`NaN/Infinity` 变 `null`
  - 无法处理循环引用
- 手写递归（面试高频）：需处理循环引用（用 WeakMap）、各种类型

```js
function deepClone(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (map.has(obj)) return map.get(obj); // 循环引用
  const clone = Array.isArray(obj) ? [] : {};
  map.set(obj, clone);
  for (const k in obj) {
    if (obj.hasOwnProperty(k)) clone[k] = deepClone(obj[k], map);
  }
  return clone;
}
```

## 易错点 / 面试追问
- 何时用哪种：无嵌套或可接受共享用浅拷贝；需完全隔离用深拷贝
- 循环引用是手写深拷贝的必考点
