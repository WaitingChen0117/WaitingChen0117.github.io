# 响应式与单位

> [!info] 一句话概括
> 用相对单位 + 媒体查询 + 弹性布局，让页面适配不同屏幕尺寸。

## 常用单位
- **px**：绝对像素，固定
- **%**：相对父元素
- **em**：相对当前元素 font-size（会层层叠加）
- **rem**：相对根元素 `html` 的 font-size（推荐做响应式基准）
- **vw / vh**：视口宽/高的 1%
- **vmin / vmax**：视口较小/较大边的 1%

## 媒体查询
```css
@media (max-width: 768px) {
  .container { flex-direction: column; }
}
```

## 响应式手段
1. **弹性布局**：Flex / Grid + `fr`、`minmax`、`auto-fit`
2. **相对单位**：rem / % / vw 替代固定 px
3. **媒体查询**：按断点切换布局
4. **图片自适应**：`max-width: 100%`、`<picture>`、`srcset`
5. **移动端视口**：`<meta name="viewport" content="width=device-width, initial-scale=1">`

## rem 适配方案
```css
html { font-size: 16px; }        /* 1rem = 16px */
/* 配合 JS 动态设置 html font-size，或用 clamp() */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); } /* 流式缩放 */
```

## 易错点 / 面试追问
- `em` 会嵌套累积（父 1.2em 子 1.2em = 1.44 倍），`rem` 只看根元素更可控
- `vw` 做字体缩放要配 `clamp()` 设上下限，避免极端屏幕过大过小
- 移动端 1px 边框问题：用 `transform: scale` 或 `0.5px`
