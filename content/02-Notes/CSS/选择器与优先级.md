# 选择器与优先级

> [!info] 一句话概括
> 优先级按 (行内, id, class/属性/伪类, 标签) 四级比较，`!important` 最高，同级看书写顺序。

## 常见选择器
- 基础：标签 `div`、类 `.box`、id `#app`、通配 `*`
- 属性：`[type="text"]`
- 伪类/伪元素：`:hover`、`:nth-child(2)`、`::before`
- 组合：后代 `a b`、子代 `a > b`、相邻 `a + b`、兄弟 `a ~ b`

## 优先级计算
用四元组 `(a, b, c, d)` 从高到低比较：
- **a** 行内样式 `style=""` → 1
- **b** id 选择器数量
- **c** class / 属性 / 伪类数量
- **d** 标签 / 伪元素数量

```
#nav .item a       -> (0,1,1,1)
div.item:hover     -> (0,0,2,1)
```
比较时从左往右，高位大的胜出。

## 特殊规则
- `!important` 覆盖一切（除了另一个 `!important` 且优先级更高）
- 同优先级：**后写的覆盖先写的**
- 继承来的样式优先级最低
- `:where()` 优先级恒为 0，`:is()` 取内部最高

## 易错点 / 面试追问
- 尽量不用 `!important`，会破坏级联、难以维护
- 优先级不进位：256 个 class 也不敌 1 个 id（概念上应视为各级独立比较）
