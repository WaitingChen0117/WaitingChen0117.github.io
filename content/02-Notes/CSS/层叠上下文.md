# 层叠上下文

> [!info] 一句话概括
> 层叠上下文决定元素在 z 轴上的堆叠顺序，z-index 只在同一层叠上下文内比较。

## 是什么
一个三维概念：HTML 元素在垂直于屏幕的 z 轴上有堆叠关系。某些属性会创建独立的"层叠上下文"，其内部元素的堆叠独立于外部。

## 怎么触发
- 根元素 `<html>`
- `position` 为 relative/absolute 且 `z-index` 不为 auto
- `position: fixed / sticky`
- `opacity < 1`
- `transform`、`filter`、`will-change`、`isolation: isolate` 等

## 易错点 / 面试追问
- **为什么我 z-index: 9999 还是被盖住？** 因为父级创建了层叠上下文，子元素再高也跳不出父级的层级。
- 层叠顺序（从下到上）：背景 → 负 z-index → block → float → inline → 正 z-index
