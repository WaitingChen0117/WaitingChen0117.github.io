# 动画与过渡

> [!info] 一句话概括
> transition 处理状态间的平滑过渡，animation + keyframes 做多阶段自定义动画；优先动画 transform/opacity。

## Transition（过渡）
状态改变时（如 hover）自动补间。
```css
.box {
  transition: transform 0.3s ease, opacity 0.3s;
}
.box:hover { transform: scale(1.1); }
```
- 属性：`transition: 属性 时长 缓动函数 延迟`

## Animation（动画）
用 `@keyframes` 定义多个关键帧，可循环、可自动播放。
```css
@keyframes slide-in {
  from { transform: translateX(-100%); opacity: 0; }
  to   { transform: translateX(0);     opacity: 1; }
}
.panel {
  animation: slide-in 0.4s ease-out forwards;
  /* name duration timing delay iteration-count direction fill-mode */
}
```

## 性能：只动这两个属性
- **`transform`** 和 **`opacity`** 可由 GPU 合成，不触发重排重绘，最流畅
- 避免动画 `width/height/top/left/margin` —— 会触发[[02-Notes/Browser/重排与重绘|重排]]
- `will-change: transform` 可提示浏览器提前提升为合成层（慎用，别滥用）

## 易错点 / 面试追问
- `transition` 需要有"状态变化"触发；`animation` 可自动播放
- `fill-mode: forwards` 让动画停在最后一帧
- 缓动：`ease` / `linear` / `cubic-bezier()` / `steps()`（逐帧）
