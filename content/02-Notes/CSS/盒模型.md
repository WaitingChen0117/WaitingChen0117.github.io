# 盒模型

> [!info] 一句话概括
> 每个元素都是一个盒子，由 content、padding、border、margin 四层组成；box-sizing 决定 width 算不算 padding/border。

## 组成
从内到外：`content`（内容）→ `padding`（内边距）→ `border`（边框）→ `margin`（外边距）

## 两种盒模型
- **标准盒模型** `content-box`（默认）：`width` = content 宽度，padding/border 往外撑
- **IE / 怪异盒模型** `border-box`：`width` = content + padding + border，更符合直觉

```css
* { box-sizing: border-box; } /* 常见全局重置，布局更可控 */
```

## 易错点 / 面试追问
- **margin 合并（塌陷）**：相邻块级元素的上下 margin 会取较大值，而非相加；父子间也可能穿透。解决：BFC、加 padding/border、用 flex/grid
- `margin: 0 auto` 水平居中的前提是元素有确定宽度且为块级
- `width: 100%` + padding 在标准盒模型下会溢出，`border-box` 可避免
